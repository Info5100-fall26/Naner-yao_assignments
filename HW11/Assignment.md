## What does expression “try … catch” do?
- The try block holds code that is tested for errors while it runs. If an error occurs, the catch block runs to handle it, so the program doesn't just stop. The two keywords always come in pairs. An optional finally block runs afterward regardless of the result.

## What does it mean when the program throws exceptions?
- When an error occurs while Java code is running - a coding mistake, wrong input, Java normally stops and generates an error message. The technical term for this is that Java throws an exception. A programmer can also use the throw keyword with an exception type, such as ArithmeticException.

## What is a Thread in Java?
A thread is a single sequential flow of control within a program. It is a very lightweight process, the smallest part of a process, that lets a program run multiple tasks at the same time, such as performing complicated tasks in the background without interrupting the main program. Running several threads in parallel is called multithreading.
